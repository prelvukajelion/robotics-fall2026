# Lab 8: Planning and Human-Aware Navigation

Students implement BFS, DFS, IDDFS and A* offline and compare standard search metrics. They then execute those routes, supplied RRT and PRM routes, and a named Nav2 baseline through one controller on two matching map/world pairs. Finally they compare human-unaware paths with human-aware potential-field refinements using navigation and social metrics.

The guide explains search, experiment controls, recorded measurements and limitations before asking students to interpret evidence. One technical synthesis connects the three missions. A separate individual reflection uses the shared course prompt.
